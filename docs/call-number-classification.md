# HKPL call number (索書號) classification reference

Source: [HKPL 館藏分類](https://www.hkpl.gov.hk/tc/collections/catalogues/library-collection-classification.html)  
HKPL uses **Dewey Decimal Classification (DDC)** for English materials and **Liu Guojun Chinese Library Classification** for Chinese materials.

The official public shelf guide lists main classes (tens). Finer numbers such as `332.6` (Investing) are DDC subdivisions under `330 Economics` and are **not** listed on that page. A suffix like `CFA` after the number is a cutter / author mark, not a separate class.
